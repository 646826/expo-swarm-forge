# Начать здесь: SwarmForge и Canyon Charms

Этот репозиторий показывает два результата одновременно:

1. **шаблон**, из которого можно начать новую браузерную игру;
2. **готовый пример Canyon Charms**, чтобы увидеть правила, графику, тесты и публикационный pipeline в одном месте.

Для первого знакомства не нужно устанавливать npm-пакеты. Нужен только **Node.js 22 или новее**.

## 1. Проверить весь проект одной командой

```bash
npm run verify
```

Команда последовательно:

1. запускает все Node-тесты;
2. проверяет шаблон и Canyon Charms;
3. собирает статические версии;
4. создаёт ZIP шаблона и ZIP игры;
5. генерирует русское PDF-руководство.

Успешное завершение заканчивается сообщением:

```text
Verification complete: tests, checks, builds, packages, and handbook passed.
```

## 2. Запустить готовую игру

```bash
npm run serve -- example/canyon-charms/dist 4173
```

Откройте:

```text
http://127.0.0.1:4173
```

Правила уровня:

- поле 8 × 8;
- цель — **5 000 очков**;
- доступно **20 ходов**;
- три одинаковых элемента исчезают;
- четыре создают фейерверк для строки или столбца;
- пять элементов, форма T или L создают динамит;
- если восемь секунд ничего не нажимать, допустимый ход подсветится;
- неправильный обмен возвращается назад и не тратит ход.

## 3. Создать свою игру из шаблона

```bash
npm run create -- my-game "My Game"
npm run check -- --project games/my-game
npm run serve -- games/my-game 4173
```

Новая папка появится в `games/my-game/`.

Менять удобнее в таком порядке:

1. `index.html` — видимые экраны;
2. `styles.css` — оформление;
3. `src/state.js` — правила экранов;
4. `src/main.js` — соединение правил с браузером;
5. `test/` — проверяемое поведение.

## 4. Как устроен SwarmForge

```text
director → gameplay → presentation → qa → director
```

- **director** уточняет результат, делит работу и принимает merge;
- **gameplay** меняет только правила и тесты;
- **presentation** отвечает за Canvas, DOM, ввод, анимацию и звук;
- **qa** проверяет игру глазами игрока, собирает скриншоты и release evidence.

Запуск локальной команды агентов:

```bash
./swarm
```

Для этого дополнительно нужны `zsh`, `git`, `tmux`, Babashka (`bb`) и хотя бы один поддерживаемый agent CLI.

## 6. Честный статус публикации

Публичный неизменяемый preview проверяется через Chrome и привязан к точному Git-коммиту.

Канонический адрес GitHub Pages станет рабочим после однократной настройки владельцем репозитория:

```text
Settings → Pages → Build and deployment → Source → GitHub Actions
```

Настоящая публикация в **Arkadium** требует внешних данных и решений: Sandbox-доступа, `gameId`, production credentials, юридической проверки и одобрения издателя. Репозиторий не подделывает эти подтверждения.
